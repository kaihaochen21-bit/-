# 《03:17，手机里多了一张我睡着后的照片》制作包

> 都市现实惊悚 / 独居安全 / 跟踪悬疑
> 竖屏 9:16 · 32 个 10 秒镜头 · 目标成片 5:20

## 使用顺序

1. 先读 01_剧本.md，确认故事逻辑。
2. 读 03_角色场景一致性.md，先生成林乔、卧室、酒店房间参考图。
3. 按 05_生成与保存规则.md 设置豆包。
4. 第一次只复制 prompts/shot-01.txt，生成首镜并验收。
5. 首镜通过后，按 06_逐日生产计划.md 分批生成。
6. 每镜保存为 shot-01.mp4 到 shot-32.mp4。
7. 手机屏幕、03:17 时间、直播提示和短信全部后期叠加，参考 08_屏幕界面与后期叠加.md。

## 文件说明

- 01_剧本.md：完整故事、五幕结构和关键台词。
- 02_32镜分镜表.md：镜头顺序、动作、结束状态和保存名。
- 03_角色场景一致性.md：人物、场景和道具锁定。
- 04_豆包逐镜提示词.md：32 条完整提示词合集。
- 05_生成与保存规则.md：豆包参数、命名和验收标准。
- 06_逐日生产计划.md：按每日额度分段。
- 07_配音与字幕.md：旁白、台词和字幕安排。
- 08_屏幕界面与后期叠加.md：手机相册、直播、短信和时间显示。
- prompts/shot-XX.txt：每镜单独的可复制提示词。
- references/角色与场景参考图提示词.md：先生成参考图。
- references/关键帧提示词.md：32 张分镜关键帧提示词。
- shotlist.json：结构化镜头数据。

## 制作原则

- 不使用 Computer Use 自动操作豆包。
- 一次只生成一镜，先验收 shot-01。
- 不让豆包生成可读文字、字幕、短信和直播界面，全部后期添加。
- 不依赖怪物、血腥、透明手和复杂特效。
- 每镜只做一个主要动作，镜头结束状态必须等于下一镜的开始状态。

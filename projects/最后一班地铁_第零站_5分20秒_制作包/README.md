# 《最后一班地铁：第零站》5 分 20 秒制作包

> 悬疑 / 心理恐怖 / 都市灵异规则
> 竖屏 9:16 · 32 个 10 秒镜头 · 目标成片 5:20

## 使用顺序

1. 先读 `01_剧本.md`，确认故事逻辑。
2. 读 `03_角色场景一致性.md`，先生成角色和场景参考图。
3. 按 `05_生成与保存规则.md` 设置豆包。
4. 第一次只复制 `prompts/shot-01.txt`，生成首镜。
5. 首镜通过后，按 `06_逐日生产计划.md` 分批生成。
6. 所有文件名必须保持 `shot-01.mp4` 到 `shot-32.mp4`。

## 文件说明

- `01_剧本.md`：完整故事、五幕结构和关键台词。
- `02_32镜分镜表.md`：镜头顺序、动作、结束状态和保存名。
- `03_角色场景一致性.md`：角色、场景、道具和连续性锁定。
- `04_豆包逐镜提示词.md`：32 镜完整提示词，可直接复制。
- `05_生成与保存规则.md`：豆包参数、命名和验收规则。
- `06_逐日生产计划.md`：按每日额度分段。
- `07_配音与字幕.md`：旁白/台词和后期字幕建议。
- `prompts/shot-XX.txt`：每镜单独的可复制提示词。
- `references/角色与场景参考图提示词.md`：先做参考图的提示词。
- `references/关键帧提示词.md`：32 张关键帧图提示词。
- `shotlist.json`：结构化镜头数据，方便后续导入工作台。

## 制作原则

- 不使用 Computer Use 自动操作豆包。
- 一次只生成一镜，先验收 `shot-01`。
- 不生成画面内可读文字；字幕和片名全部后期添加。
- 不依赖透明手、怪物变身、粒子、光晕和血画面。
- 每镜只做一个主要动作，镜头结束状态必须等于下一镜的开始状态。

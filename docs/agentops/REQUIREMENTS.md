# 需求规格

> 状态：TASK-009 完成后的下一步验证规格
> 最后更新：2026-10-26
> 负责人：requirements-analyst / orchestrator

## 产品目标

用最小成本验证：是否存在愿意为“15–60 秒 AI 视频切片、剪辑或产品演示”支付小额定金的真实买方，并形成可重复的首触、样片、报价和交付流程。

## 成功指标

| 指标 | 目标值 | 验证方式 |
|---|---|---|
| 合格线索数 | ≥20 条公开线索 | `LEADS.md` 中每条有 URL、原话、联系路径 |
| 高分线索数 | ≥8 条评分 ≥7 | 按 10 分制人工评分 |
| 个性化首触 | 仅联系高分线索，逐条撰写 | 发送前由用户本人确认 |
| 真实沟通 | ≥2 次 | 有回复截图/记录，不伪造 |
| 付费试单 | ≥1 个 | 有书面范围、定金和交付条件 |
| 交付成功率 | 首单按约定验收 | 有预览、修改记录和最终文件 |

## 用户故事

| ID | 用户故事 | 优先级 |
|---|---|---|
| US-001 | 作为内容团队，我希望先看到 15–30 秒相关样片，以便判断你是否理解我的项目 | Must |
| US-002 | 作为买方，我希望明确价格、修改轮次和交付格式，以便避免无限返工 | Must |
| US-003 | 作为服务方，我希望在投入完整制作前拿到小额定金，以便降低白做风险 | Must |
| US-004 | 作为买方，我希望真实展示产品，不要虚构功能或伪造案例 | Must |
| US-005 | 作为项目负责人，我希望所有联系和报价经过人工确认，避免骚扰和错误承诺 | Must |

## 功能需求

| ID | 需求 | 验收标准 | 优先级 | 依赖 |
|---|---|---|---|---|
| FR-001 | 线索评分 | 每条线索按清晰度、预算、可联系性、能力匹配、时效性评分，并记录证据 URL | Must | 无 |
| FR-002 | 个性化样片 | 针对目标线索生成 15–30 秒样片，引用其真实需求，不用同一模板冒充定制 | Must | FR-001 |
| FR-003 | 对外发送门控 | 私信、评论、邮件和报价必须由用户明确确认后才发送 | Must | 无 |
| FR-004 | 需求确认清单 | 联系前确认交付物、数量、时间、预算、验收人、版权和付款节点 | Must | 无 |
| FR-005 | 小额定金试单 | 试单范围限定为单条/限定镜头/单集片段，并约定修改轮次 | Must | FR-004 |
| FR-006 | 交付记录 | 记录预览、修改、终稿、工程文件和回款状态 | Should | FR-005 |
| FR-007 | 版本化交付 | 支持 9:16、16:9、1:1 及不同字幕/CTA 版本 | Should | FR-005 |

## 非功能需求

| ID | 类别 | 要求 | 验证方式 |
|---|---|---|---|
| NFR-001 | 隐私 | 只使用公开商务信息；不购买、转卖或批量采集联系方式 | 审查 `LEADS.md` 和发送记录 |
| NFR-002 | 真实性 | 不虚构客户、功能、模型能力、预算或回复 | 人工核对每项证据 |
| NFR-003 | 版权 | 使用有授权的素材、音乐、字体、声音和角色；记录来源 | 项目素材清单 |
| NFR-004 | AI 标识 | 按发布平台和适用规则标明 AI 生成/合成内容 | 发布前检查 |
| NFR-005 | 交付 | 视频可播放，无音画不同步、字幕截断、黑帧和明显静音错误 | FFmpeg/人工验收 |
| NFR-006 | 财务 | 不接无付款保障的大额整季项目；收款前不交无水印成片/工程文件 | 合同与付款记录 |

## 范围外

- 自动群发、自动评论、自动加微信/QQ。
- 购买线索数据库、破解平台限制、爬取登录后隐私数据。
- 未经授权的声音克隆、真人换脸、影视切片和擦边内容。
- 无案例却宣称具备复杂 3D、LoRA 训练或高一致性整剧能力。

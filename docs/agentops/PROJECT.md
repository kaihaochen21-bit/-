# 项目合同

> 状态：进行中
> 最后更新：2026-10-26
> 负责人：orchestrator

## 最终目标

从公开、明确、可联系的 AI 短剧 / AI 视频需求中筛选真实买方，以低风险付费试单验证可重复服务，争取首单并形成“需求侦察 → 样片 → 报价 → 交付 → 复盘”的闭环。

### 已完成子项目

为“刘春霖 AI 小楷书房”制作 20–30 秒竖屏产品演示视频，作为早期客户送样和作品集案例。该案例保留，但不再等同于整个项目目标。

## 项目类型

AI 视频服务需求验证 / 客户送样 / 小额定金试单

## 目标用户与使用场景

- P0：有脚本、素材或明确业务目标，短时间内需要 15–60 秒 AI 视频的中小商家、内容团队、AI 产品作者。
- P0：需要短剧切片、字幕、音效、配音、调色、封面和工程归档的短剧/漫剧工作室。
- P1：需要试播集、分镜预演、角色/场景资产 bible 的 IP 方和承制团队。
- P1：需要多语言、多比例、多 CTA 版本矩阵的广告/出海团队。
- 非目标：只想买课、套提示词、免费试用完整成片的人；无授权换脸、声音克隆、擦边或侵权项目。

## 纳入范围

- 公开需求扫描、线索评分、排除项和来源记录。
- 针对具体需求制作 15–30 秒个性化样片。
- 人工审核后的一次性联系话术和报价问题清单。
- 小额定金试单：限定镜头/单条视频、明确修改轮次、带水印预览。
- 基础后期：剪辑、字幕、配音、音效、调色、封面、比例适配和工程文件整理。
- 需求确认、版权/授权边界、AI 标识和付款节点记录。

## 排除范围

- 未获用户确认的私信、评论、邮件或对外报价。
- 群发、购买联系方式、绕过登录或采集隐私数据。
- 低价整季 AI 短剧承诺后硬交付。
- 未经授权的真人换脸、声音克隆、影视素材切片、擦边或侵权 IP。
- 超出当前能力的 Blender 3D 建模/绑定/复杂动作项目，除非明确转介或组队。

## 交付物

- `docs/agentops/RESEARCH.md`：需求、缺口、证据和切入建议。
- `docs/agentops/LEADS.md`：可复核线索、评分和联系边界。
- `docs/agentops/REQUIREMENTS.md`：下一步验证的需求与验收标准。
- 至少 2 条与目标线索对应的 15–30 秒样片。
- 人工审核后的首触话术与报价问题清单。
- 首单试做后的交付、修改和回款记录。

## 成功标准

- 首轮筛选出至少 20 条公开线索，保留 8 条 7 分以上线索。
- 至少 2 条线索进入真实沟通，且能确认交付物、预算、时间和决策人。
- 至少 1 个客户接受限定范围的付费试单。
- 不出现群发、虚假案例、未授权素材或未确认外发。
- 每次联系和回复都有记录，能复盘为什么成交或失败。

## 约束

- 运行平台：Windows / 本地 FFmpeg + Edge TTS + MCP 低代码管线。
- 时间或预算：研究阶段 0 付费 API；付费生成需人工确认。
- 技术限制：以静态分镜、产品截图、字幕、配音、剪辑和版本化为强项；复杂 3D/动作/角色一致性不是默认能力。
- 权限边界：遵守 `AGENTS.md`；外部发送、付费、发布和合并必须人工确认。

## 风险门控

付费生成、对外发送、公开发布、购买服务、合并主分支和任何真实客户承诺必须人工确认。
